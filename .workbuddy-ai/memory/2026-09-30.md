## 第二阶段：双端交付（网站可部署化 + 原生微信小程序）

**背景**：UI 初版完成后，用户要求①网站可部署上线 ②完整原生微信小程序。已确认：小程序做完整原生版；网站构建时接入 Notion API 自动同步；网站沿用现有原生静态站（不重写 React）。

**团队协作**：software-company 专家团走标准 SOP —— 许清楚(PRD) → 高见远(架构) → 寇豆码(实现) → 严过关(QA)。
产出文档：
- `deliverables/software-company/selfweb-prd.md`（30KB，20 条需求池 P0/P1/P2、数据契约、双端 UI 规格、10 个待确认问题）
- `deliverables/software-company/selfweb-architecture.md`（56KB，1172 行，含文件清单/类图/时序图/任务列表/依赖包/共享知识）
- `docs/system_design.md`、`docs/class-diagram.mermaid`、`docs/sequence-diagram.mermaid`

**架构决策**：
- **零依赖**：`package.json` 的 dependencies 和 devDependencies 均为空，用 Node 18+ 内置 `fetch`/`fs`/`zlib`
- **双端同源**：`tools/build.js` 一次归一化 → 同时产出 `site/data.js`(window.SITE_DATA) 和 `miniprogram/utils/data.js`(module.exports)，实测 JSON 完全一致
- **三级降级链**：① NOTION_TOKEN 且请求成功 → ② 本地 `data/site-data.local.json` → ③ 内置兜底。任何情况都不 exit(1)，构建必成功
- **部署目录**：`site/dist/`（Vercel `vercel.json` / Netlify `netlify.toml` 已配）
- **小程序**：单包无需分包（代码~150KB + 数据21KB + 图标<30KB），tabBar 5 项 = 首页/AI/图书馆/方法论/更多（旅行+Words 归入「更多」页）

**修复的 3 个数据缺陷**：
1. 《明朝那些事》`cover="attachment:1.jpg"` 无效占位符 → 归一化为 `""` + 保留 `coverFallback`
2. `modules[].count` 声明 library=14/words=80，实际 12/74 → 一律以真实 `list.length` 校正
3. 所有条目无稳定 id → 按 `book-001`/`article-003`/`trip-001`/`word-021`/`ai-001` 规则生成（共 99 个，无重复）

**技术要点（重要，后续复用）**：
- **零依赖 PNG 生成**：本机无 sharp/PIL。用纯 Node `zlib` 手写 PNG 编码（crc32 + IHDR/IDAT/IEND chunk）生成 tabBar 图标，见 `tools/make-icons.js`。已验证可用于 81×81 图标与 1200×630 OG 图
- **构建幂等性修复（关键 bug）**：原 `build.js` 把 SEO 注入结果**回写 `site/index.html`**，导致重复构建时 meta 标签累积（og:title 每次 +1）。修复方案：① 新增 `templates/site-template.html` 作为只读纯净模板；② `seo.js` 新增 `readTemplate(root)` 与 `stripInjected(html)`；③ 所有 SEO 产物只写 `site/dist/`；④ `copySiteToDist()` 跳过生成物避免覆盖。实测连续 3 次构建 meta 数量恒定
- **SEO 方案**：构建时生成 6 个入口 HTML（index + 5 模块），各含独立 title/description/canonical/OG/Twitter，模块页内联 `window.__INITIAL_VIEW__` 供 SPA 直接渲染对应视图

**验证产物**：
- `tools/verify.js` —— 构建产物校验，25 项全通过
- `tools/normalize.js` / `tools/generate.js` / `tools/notion.js` / `tools/seo.js` / `tools/make-icons.js`

**待办**：
- 小程序 10 个页面实现（T06 列表页/筛选 + T07 详情页/分享）
- QA 双端验收（PRD §9 三份清单）
